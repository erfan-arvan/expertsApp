Practice Snippet

Before the study tasks, you will work on one practice snippet to get familiar with the interface.

  • You will see a Java method and a question about it. The code stays visible while you answer.
  • Work out what value the method returns for the given input and type it in the box.
  • Some questions list assumptions about code outside the snippet. Use them when working out the answer.
  • Underlined method names open their Javadoc.
  • After you submit your answer, you cannot change it. You will then be asked whether you have seen the code before.
  • Keep the timer running while you work, and pause it if you stop.

Practice complete

The study tasks start next. They work exactly like the practice snippet.

  • You cannot go back to earlier snippets.
  • After every five snippets, the study pauses for a short break at your seat.
  • Halfway through, you get a longer break during which you may leave the room quietly.
Questions or issues? Pause the study and raise your hand, or contact ea442@njit.edu.
